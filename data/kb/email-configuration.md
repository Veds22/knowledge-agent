# Email Configuration Guide

## Overview
The company uses Microsoft 365 (Outlook) for all corporate email. Personal email clients may be used with IT approval and proper configuration.

## Setting Up Outlook

### Desktop (Windows / macOS)
1. Open Outlook and click Add Account.
2. Enter your corporate email: `firstname.lastname@company.com`.
3. Outlook auto-discovers settings via Microsoft 365.
4. Complete MFA when prompted.
5. Allow profile setup to complete (up to 5 minutes for large mailboxes).

### Mobile (iOS / Android)
1. Install Microsoft Outlook from the App Store / Play Store.
2. Add account → enter corporate email.
3. Complete MFA.
4. Accept the MDM policy prompt (required for corporate email on mobile).

### Web Access
Access email at `https://outlook.office.com` with your corporate credentials.

## Email Signature Policy
All outgoing external emails must include the company-approved signature:
```
[Full Name] | [Job Title]
Company Name | [Department]
T: +91 [phone] | E: [email]
www.company.com
```
Download the approved signature template from the IT portal.

## Mailbox Limits
- Mailbox size: 50 GB (auto-expanded for executives).
- Attachment size limit: 25 MB per email.
- For large file sharing, use SharePoint or OneDrive links instead of attachments.

## Out of Office
1. Outlook → File → Automatic Replies.
2. Set date range and compose internal and external messages separately.
3. External auto-replies should not disclose internal project details.

## Distribution Lists and Shared Mailboxes
- Request new distribution lists at `https://itportal.internal/email`.
- Shared mailbox access: requires manager approval + IT setup (allow 1 business day).
